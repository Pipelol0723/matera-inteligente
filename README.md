# Matera inteligente

Núcleo de la matera inteligente: un servicio que, dada una especie y una medición de humedad del sustrato, luz y temperatura, diagnostica el estado de la planta, y un front web que lo consume.

Proyecto de corte de Arquitectura de Software, semestre 2026-03.

> En construcción. Las instrucciones para ejecutar el backend, el front y las pruebas se agregan a medida que cada parte exista.
